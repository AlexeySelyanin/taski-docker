# как делать парелльную ветку и рабоать в ней

Шаг 0: Создание ветки review
В задании чётко сказано: не работай в main. Это правило хорошего тона в реальной разработке. Мы будем делать всё в отдельной ветке, чтобы не сломать основной код.

Открой терминал в папке с проектом и выполни:

bash
git checkout -b review
Зачем это нужно?

main — это священная ветка, где лежит стабильный код.

review — это твоя песочница. Ты можешь делать там что угодно, и если что-то пойдёт не так, основная ветка не пострадает.

Теперь ты в ветке review. Можешь проверить это командой git branch. Там должна быть звёздочка напротив review.
